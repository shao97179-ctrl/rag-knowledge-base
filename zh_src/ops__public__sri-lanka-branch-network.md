# 中兴银行有限公司 – 斯里兰卡分行网络

中兴银行有限公司在斯里兰卡建立了稳健布局，32 家分行战略性分布于所有主要省份。这一广泛覆盖使斯里兰卡各地客户都能便捷获得广泛的银行服务，涵盖零售银行、中小微企业银行、汇款和数字方案。每家分行均可支持个人与企业客户，推动全国金融普惠。
