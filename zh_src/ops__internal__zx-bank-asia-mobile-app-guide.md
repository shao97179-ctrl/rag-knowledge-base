## 2. 如何开通手机银行

1. **打开中兴银行亚洲版应用**。
2. 点击 `注册 / 激活`。
3. 输入您的注册手机号和客户号/账号。
4. 通过发送至手机的 OTP 完成认证。
5. 设置您偏好的登录 PIN 或配置生物识别认证（指纹/面容 ID）。
6. 如提示，完成 e-KYC 核验。

## 4. 应用功能

### 账户管理

- 查询储蓄/活期账户余额。
- 查看交易历史和迷你对账单。
- 实时跟踪定期存款、零存整取和贷款详情。

### 资金转账

#### **中兴银行内部 / 跨行**
1. 点击 `资金转账`。
2. 选择中兴银行或跨行（NEFT/IMPS/UPI）。
3. 选择/添加收款人（见下文）。
4. 输入金额和备注。
5. 通过 PIN/OTP 确认。

#### **添加收款人**
1. 进入 `资金转账` → `收款人管理`。
2. 选择 `添加收款人`。
3. 输入收款人账户信息（姓名、银行信息、IFSC）或 UPI ID。
4. 通过 OTP 验证。
5. 收款人添加完成——开始转账。

### 账单支付与二维码

- 缴纳电费、水费、燃气费、手机费和信用卡账单。
- 在商户处扫码支付，或用于快速转账。

### 卡片

#### **查询、申请与管理信用卡/借记卡**
- 查看现有卡片及使用摘要、还款日、对账单和积分。
- **冻结卡片**：选择卡片 → 更多选项 → 冻结（立即生效）。
- **重置卡 PIN**：选择卡片 → 修改 PIN → 输入原 PIN 和新 PIN。
- **申请新卡**：卡片菜单 → 申请新卡 → 选择信用卡或借记卡 → 填写申请并提交材料。

#### **设置卡片限额**
- 进入 `卡片管理`。
- 选择卡片并点击 `设置交易限额`。
- 调整 ATM、POS、线上、非接触支付限额——保存更改。

### 贷款

- 查看所有贷款、月供、还款计划和下载对账单。
- 申请新贷款：住房、个人或车辆 → 填写表格 → 上传 KYC → 跟踪状态。

### 奖励

- 在 `奖励` 标签页查看当前积分。
- 即时兑换积分，换取代金券、返现或礼品卡。

### NRI 与财富

- 使用 NRI 服务、共同基金、财富咨询，并发起投资。

### 聊天机器人 – **小雅**

- 向小雅咨询账户问题、产品信息、快速查询余额和交易支持。
