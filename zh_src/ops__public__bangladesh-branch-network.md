# 中兴银行孟加拉国分行网络

中兴银行在孟加拉国保持稳健布局，通过战略性布设的分行网络促进金融普惠与增长。全境共 18 家分行，分布于达卡、吉大港、库尔纳、拉杰沙希和锡尔赫特等主要地区，为个人和企业提供便捷的银行服务。每家分行均提供全面银行设施，涵盖零售与对公银行、数字化开户及汇款支持。
