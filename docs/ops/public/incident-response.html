故障响应手册

本手册适用于生产环境故障的分级、响应、升级与复盘。所有值班人员必须熟悉。

故障分级

级别定义响应时限初判时限
P0核心交易不可用、数据丢失风险5 分钟30 分钟
P1主要功能降级或大面积超时15 分钟1 小时
P2非核心功能异常1 小时次工作日
P3咨询、优化建议次工作日次工作日

响应流程

  1. 值班工程师在告警群确认故障，5 分钟内响应并认领。
  2. P0/P1 立即拉起临时作战群，通知值班经理和相关研发负责人。
  3. 先止损再定位：必要时摘流量、限流、回滚最近一次变更。
  4. 每 30 分钟同步一次进展，直到故障关闭。

数据库连接池耗尽、慢查询导致的核心接口超时，通常按 P1 处理；如果影响支付主链路则升级为 P0。

升级路径

值班工程师 → 值班经理 → 技术负责人 → CTO。P0 故障需同步通知客户成功团队，由其在 30 分钟内通知受影响客户。

值班与复盘

  • 值班电话：400-000-1234；值班群：星云-oncall。
  • P0/P1 故障必须在 3 个工作日内输出复盘报告，包含时间线、根因、改进项和责任人。
  • 复盘报告归档到运维知识库，并在下一次值班交接中宣讲。
